# Логотипы Waiting Paws — концепты и мокапы

31 вариант логотипа и иконки (26 идей, у части есть вариации a/b) в 8 палитрах. Всё нарисовано
кодом, без растровых генераторов: каждый вариант — функция в `logos.js`, которая возвращает SVG.

**Выбрано для приложения:** `07` «Песочные часы» в палитре «Ночь (как в приложении)» (до этого стояла `05b`).
Исходники иконки лежат в `../app-icon`, PNG — в `App/Resources/Assets.xcassets/AppIcon.appiconset`.

## Файлы

```
logos.js      — палитры, хелперы (лапа, собака со спины, дуги) и все концепты; общий код для браузера и node
index.html    — галерея-мокап: палитры, мелкие размеры, домашний экран iPhone, связка с надписью, экспорт SVG/PNG
build.js      — node build.js → svg/, png/, sheets/
app-icon.js   — node app-icon.js → иконка приложения (iOS 1024 без альфы + macOS 16…1024 в сетке 824/1024)
serve.js      — node serve.js [порт] — раздать галерею в локальную сеть (по умолчанию 8765)
svg/          — каждый вариант в своей палитре по умолчанию; svg/all-palettes/ — все варианты × все палитры
png/          — PNG 1024 тех же вариантов
sheets/       — листы-превью по палитрам (SVG + PNG)
```

`svg/`, `png/` и `sheets/` пересоздаются целиком при каждом `node build.js`, руками их не правьте.

## Как посмотреть

- Открыть `index.html` в браузере прямо из Finder.
- Или показать в локальной сети: `node Design/logos-v2/serve.js` — скрипт напечатает ссылку вида
  `http://192.168.x.x:8765/`. В Claude Code это конфигурация `logos` в `.claude/launch.json`.

## Как добавить или поменять вариант

1. В `logos.js` добавить `add('27', 'Название', 'night', 'Идея…', () => \`…SVG 1024×1024…\`)`.
   Цвета задавайте токенами: `F` основной, `A` второй акцент, `M` приглушённый, `K` вырез цветом фона,
   `H` светлый, `E` черты морды (глаза, нос). Палитры подставят конкретные цвета.
2. Добавить slug в `SLUG` и выполнить `node build.js`.
3. Чтобы сделать вариант иконкой приложения, поменять `CONCEPT`/`PALETTE` в `app-icon.js` и выполнить `node app-icon.js`.

## Ограничения

- `23` (эмблема) и `26` (надпись) используют шрифт Arial Rounded MT Bold как текст; для печати и сайта их
  нужно перевести в кривые (например, в Figma). Остальные варианты — чистая геометрия без шрифтов.
- Первые простые SVG лежат в `../logo-vector*`. Оставлены только как архив идей.
