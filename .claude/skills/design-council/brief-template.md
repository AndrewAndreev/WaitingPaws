## Шкала (для каждого кейса)

<!-- Шкала из критерия. Для критерия по умолчанию: -->
- **10** — минимально: ничего нельзя убрать без потери; цель экрана понятна за секунду без чтения; текст только
  там, где без него явно хуже; слова тренера видны и связаны с настройками там, где из них что-то разобрано; не
  уступает референсам в чистоте.
- **8** — одна-две лишние детали или поясняющие строки.
- **6** — заметно перегружено или цель размыта.
- **4** — перегружено, главное теряется.
- **2** — хуже базы (main).

Количество функций и подсказок — не плюс: каждая лишняя строка, подпись, состояние или кнопка — минус.

## Формат ответа (по-русски, 900–1800 слов)

Для каждого кейса:
```
### Кейс N — <название> — K/10 (раунд {N-1}: M/10)
**Цель экрана (в одной фразе):** …
**Убрать / заменить UI вместо текста:** — <экран/кадр>: «<текст или элемент>» → убрать | заменить на <что именно>
**Переусложнено:** …
```
Если кейс 10 — только полировка, которая не мешает 10. Если оценка ниже прошлой — объясни, что стало хуже.

Затем `### Главное до 10/10` — до 8 правок по отдаче, нумерованным списком. Последние две строки:
```
OVERALL_SCORE: N/10
BETTER_THAN_REFERENCES: yes|no
```
(«yes» — только если по этим критериям чище и понятнее референсов во всех кейсах.)

## Правила
- Только чтение: ничего не меняй, не собирай, не запускай. Код в `{repo}/App/Sources` можно читать.
- Не ищи других референсов в интернете. Не выдумывай того, чего не видно.
